# printf

Réimplémentation partielle de `printf` en C.

## À propos

Ce projet consiste à recréer une version personnalisée de `printf`, avec prise en charge d’un ensemble de conversions formatées.

## Conversions généralement supportées

- `%c`
- `%s`
- `%p`
- `%d`
- `%i`
- `%u`
- `%x`
- `%X`
- `%%`

> Ajuste cette liste selon ton implémentation réelle.

Utilisation
